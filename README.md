I want you to build a virtual cycling platform like zwift. Zwift is a multiplayer, online cycling and running physical training program that enables users to interact, train, and compete in a virtual world.
but start with something that I can use it for my own personal use, which means rather than paying pricy premium, I have my own virtual world that i can just plugin my indoor bike
